# Chili3D coding guidelines

## Build & Test

```bash
npm run dev            # Rspack dev server → localhost:8080
npm run build          # Production build (Rspack + SWC)
npm run test           # All tests (Rstest + Happy-DOM); npm run testc = with coverage
npm run check          # Biome lint + auto-fix (run before commits)
npm run format         # Biome + clang-format across all files
npm run build:wasm     # C++ → WebAssembly (CMake + Emscripten); setup:wasm = one-time deps

npx rstest packages/core/test/result.test.ts   # single file
npx rstest -t "should handle error case"       # filter by name
```

## Monorepo Structure

Browser-based parametric 3D CAD: OCCT C++ kernel compiled to WebAssembly, rendered with Three.js. npm workspace under `packages/`:

```
web ──> builder ──> app ──> core
                  ──> i18n / three / wasm ──> core
                  ──> ui ──> core + element
                  ──> parametric ──> core
```

- **`core`** — Everything abstract: shape interfaces, math, document model, reactive data (`Observable`, `Binding`, `PubSub`), `Result<T,E>`, undo, commands, serialization, plugins, services, UI abstractions
- **`parametric`** — Parametric feature-list bodies (Onshape-style) plus the 2D sketch module (`src/sketch/`): the sketch side wraps the garlic constraint solver (`packages/parametric/lib`, init via `initGarlic()`/`initGarlicSync()`) with `SketchSolver` + serializable `SketchNode`; the solver seeds virtual datum entities — origin + X/Y axes under reserved negative ids (`sketchModel.ts`, pinned by unserialized internal Fix constraints, net-zero dofs) — so constraints can target the origin/axes: datum refs serialize as ordinary constraints, can't be dragged/deleted, entity picks opt into axes via `pickEntity(..., { datum: true })`, and auto-constraints snap new points onto the origin; a drag target pinned onto a line/axis is projected onto that line in `dragTo` (garlic's coarse solve cannot converge from far off-manifold positions — the point would drift off its constraint and eventually surface as a bogus "Conflicting" report), and fine solves run a one-pass incidence repair (`repairIncidenceResiduals`) that snaps residual-violating points back onto their line/circle/arc; the body side's `ParametricBodyNode` replays an ordered `featuresJson` list (extrude/revolve from a referenced sketch, fillet/chamfer via edge fingerprints in `features/edgeRef.ts` (pieces of a boolean-split edge share one tracked id; a capture-time `splitPiece` flag on the `EdgeRef` keeps a picked piece from silently growing back to the whole span when a later upstream edit moves the pieces apart — zero exact matches then resolves to the clear nearest piece or fails "Edge match is ambiguous after rebuild"), boolean against tool nodes, `variable` features defining expression scope) without shape snapshots; per-kind behavior lives in `features/` behind `registerFeature`. Extrude can restrict which sketch profiles are extruded: `ExtrudeFeatureData.profiles` stores `ProfileRef` fingerprints (`features/profileRef.ts` — boundary-edge `EdgeRef`s re-matched by `resolveProfiles` in `features/profileBuilder.ts`; on the crossing path a region's primary identity is the sorted set of sketch entity ids bounding it (kernel-reported per region by `facesFromEdges`, attached via a WeakMap keyed on the region face), tiebroken within a set by the bbox-center/area region fingerprint, which is also the fallback when no candidate carries the set — e.g. the crossing disappeared); faces are picked directly in the viewport at creation time or re-picked via the feature row's reselect menu — a sketch shows its closed profile faces by default (`SketchNode.showProfileFaces`, off only while the sketch editor is active) so profile faces are always pickable, and face picks default to filled-face highlight/selection tints (`app/src/picker.ts`). Creating an extrude/revolve hides the consumed sketch (`visible = false`, inside the command's transaction so undo restores it); the sketch editor forces the node visible for the session and restores the pre-edit visibility on exit without touching the undo history. While a sketch is edited, every body whose shape depends on it is rolled back to the sketch's timeline position (Fusion-style, `src/sketch/sketchRollback.ts`): `computeSketchRollback` seeds each body with its first feature referencing the sketch, capped by the capture-time anchor `SketchData.refPositions` (the body's feature count when the sketch first referenced it, recorded at face-pick creation and by `sketch.projectEdges`, carried through the solver's `toData`/`loadData` like `externalRefs`; an anchor at the current feature count hides nothing and is skipped), then propagates to a fixpoint so a body boolean-consuming a rolled-back body rolls back to the referencing feature as well; the editor applies it via the runtime-only `ParametricBodyNode.setRollbackIndex` (never serialized, never transacted, cleared in `dispose`, and also used by the fillet/chamfer reselect pick for its pre-feature preview), so the consuming feature and everything after it stay hidden for the session and the plane/external refs resolve against the capture-time geometry, while earlier features keep re-evaluating with their current parameters — downstream features update on exit rather than live during the session. Nested sketch loops follow even-odd semantics (`sketchProfiles`): an inner loop becomes a hole of the containing profile (`shapeFactory.face([outer, ...holes])`) unless it is explicitly selected as a solid profile. Open chains (dangling entities) are skipped when building profiles; only a sketch without any closed loop fails with "Sketch profile is not closed". When sketch edges cross mid-span, T-touch another edge's interior, or overlap collinearly (detected via `IEdge.intersect` plus an endpoint-on-interior probe at the shared `INCIDENCE_TOLERANCE` from `sketchModel.ts` — the solver's incidence-repair tolerance, so both layers agree on "on the edge"; the kernel's `intersect` reports nothing for parallel curves, and a solver residual can leave an endpoint a hair off its constraint edge; plain shared-vertex contacts stay on the connectivity path), `sketchProfiles` instead routes all edges through `shapeFactory.facesFromEdges` (kernel side in `cpp/src/factory.cpp`: `BOPAlgo_Splitter` at mutual intersections, then `BOPAlgo_BuilderFace` on a giant base face — FreeCAD's FaceMakerBuildFace recipe), which returns every minimal bounded region as a profile; even-odd no longer applies on that path. Multi-profile extrudes fuse into one solid when the prisms touch (`booleanFuse` after a bounding-box precheck, falling back to a compound for disjoint profiles or a failed fuse); the tracked path maps ids through `booleanFuseTracked`. The extrude command's options tab offers an operation dropdown (new/join/cut/intersect) and a symmetric toggle: `ExtrudeFeatureData.symmetric` sweeps each profile both ways (tracked: the mirrored half's seed ids take a `:neg` suffix), and `ExtrudeFeatureData.operation` (a `BooleanOperation`) combines the prism with the host body's preceding shape — the command auto-detects the target as the first body whose bounding box intersects the prism (no target picking) and appends the feature to it instead of creating a new body, falling back to a standalone body when nothing intersects; sketch-sourced operations evaluate through the tracked boolean (`extrudeOperationTracked`) and press-pull operations through `pressPullOperationTracked` (the swept tool seeded positionally as `id:tool:fN`/`eN`; the kernel's prism history never reports a prism's top face, so the sweep seeds it synthetically as `${seed}:top`), ids mapped by `mapOperationIds`, so downstream fillet/chamfer edge ids and later press-pull face picks survive rebuilds. Extrude also works press-pull style on planar faces of a parametric body: `ExtrudeFeatureData.source` (`{ nodeId, profiles }`, replacing `sketchId`) re-matches the faces on the source node's current shape — or on the feature's own input when the source is the host body itself (the body never watches itself) — and sweeps each face along its live outward normal; each `ProfileRef` carries the picked face's tracked id (`captureProfileRef(face, id)`), so rebuilds claim by identity first (`idsOverlap`: a face split by a later cut keeps one id across its pieces, and a face (or edge) MERGED from several combines their ids into a compound — `combineIds` over the kernel's multi-valued `faceAncestors`/`edgeAncestors` history, mapped by `mapBooleanIds`/`mapOperationIds` and matched by `idsOverlap` (`resolveById` in `features/edgeRef.ts` too, so a fillet/chamfer picked on a collinear-merged edge re-matches every piece after a re-split) — so pieces of a later re-split all intersect the ref), falling back to the world-coordinate fingerprint when the id is absent or gone entirely. After every successful rebuild, a profile-matching extrude's fingerprints are re-anchored to the geometry it actually matched (`refreshProfileRefs`, fed by `ShapeTracking.resolvedProfiles`; untransacted, no shape change), so consecutive sketch edits measure drift from the latest match instead of accumulating against the pick-time refs — without it, moving several profiles in sequence drifts into an ambiguous match. The revolve command picks sketch profile faces (shared `SelectSketchProfilesStep` from `commands/extrudeCommand.ts`, parameterized with an `allowNode` predicate) plus any line edge as the axis, and takes its angle from the options-tab `@property`; `RevolveFeatureData.axisSource` (`{ nodeId, edge: EdgeRef }`) keeps the axis a live reference — `nodeIds` includes the source so its edits re-evaluate the body and `resolveAxis` re-matches the edge on the source's current shape, falling back to the world-space `axis` snapshot when the source is gone. Faces the kernel's revolve history cannot report are seeded synthetically instead of positionally (`seedHistoryLessFaces`): a partial revolve's end cap takes `${seed}:cap`, and a full turn's end rings — dropped from the history at exactly 360° — take the sweeping profile edge's seed, attributed geometrically by the edge's midpoint lying on the ring's surface. Numeric parameters accept expression strings (`features/expression.ts` — safe parser, no `eval`; trig in degrees). Rebuilds reuse a per-feature cache (feature JSON + variable scope + input/refs shape identity) and dispose evicted intermediate shapes; referenced nodes are watched so edits re-evaluate the chain — and a feature that reads a sketch first re-resolves that sketch's external references against the in-flight timeline (`followReferencedSketches`, via the public `SketchNode.followExternalRefs`, which the source-watch handler also uses), so the chain's first pass already works on post-edit geometry: without it a stale pass can fail (a cut whose sketch no longer intersects the rebuilt body becomes a no-op, and the error then surfaces on a downstream fillet as "Edge not found after rebuild"), and since a failed chain keeps the old shape, the watch-based catch-up would never run — the chain would wedge with the wrong feature blamed. Boolean features consume their tool nodes by default (`consumeTools`): tools become children of the body via `NodeChildList` (`core/src/model/childList.ts`, the linked-list plumbing behind `INodeLinkedList`, shared with `FolderNode`) — hidden from the scene, still editable from the model tree. The property panel renders the list through core's `IFeatureListNode` contract (`core/src/model/featureList.ts`); its optional `referencedNodes()` exposes feature-referenced sketches, which the model tree shows as non-draggable mirror rows under the body (`ui/src/project/tree/treeItemReference.ts`) — double-clicking one enters sketch editing via the existing `nodeDoubleClicked` PubSub topic. A sketch created on a body's face stores a `PlaneFaceRef` (`src/sketch/planeRef.ts` — tracked `faceId` + normal/offset fingerprint): resolution trusts an exact id hit while the face's normal still matches, then narrows the fingerprint contest to faces whose ids overlap the stored one (`IBodyTrackingNode.faceIndexesOfId` — the descendant pieces of a re-split merged face, so an unrelated nearer face never wins), and only then falls back to the closest fingerprint match over all faces. Sketches also support external references to other nodes' edges (`src/sketch/externalRef.ts`): a sketch created on a solid's face captures the face's boundary edges, and the `sketch.projectEdges` command adds more later; refs serialize in `SketchData.externalRefs` (`ExternalRefData` — `EdgeRef` fingerprint + world-space UV snapshot + reference/profile role) under reserved entity ids from -100 down (allocated from the monotonic `externalIdSeq`/`entityIdSeq` counters serialized on `SketchData` — a deleted id is never reissued, since entity ids key the ProfileRef region-identity sets), the solver seeds them pinned like the datum (net-zero dofs, unserialized as entities; datum and external entities live in the regular entity tables under a `fixed` marker — `SketchSolver.isFixed` — keeping reads JS-side and rejecting drag/param/delete) so constraints can target them, `generateShape` re-resolves each ref against its source node before building — a parametric-body source is read at the sketch's timeline anchor (`refPositions`) whenever the body's feature count has grown past it: the body exposes its per-feature-list chain states (shape + tracked ids) via the runtime `timelineStateAt(index)` (`IBodyTimelineNode` in `features/bodyTracking.ts`, fed by `evaluateChain` and swapped atomically with the feature cache; while a chain run is in flight its partially built timeline is what `timelineStateAt` returns, so mid-chain ref resolutions see the run's own rebuilt states), whose stand-in drives the same id-then-geometric match with the stand-in's OWN ids — so an edge a downstream feature consumed (a cut into it) still resolves in full instead of dangling or re-anchoring to a surviving split piece, Onshape-style (untransacted; a ref whose edge was split into pieces that still cover the stored curve — e.g. a boolean inserting a vertex — stays resolved with its original snapshot and full-span fingerprint, only the dead kernel edgeId being dropped; a dangling ref keeps its stale snapshot and renders red, and a profile-role one still builds profiles from that frozen geometry — the sketch degrades instead of failing "not closed" — until a later rebuild re-matches the edge, clears the flag and freshens the geometry; a dangling profile-role ref additionally surfaces as a feature-level warning ("Sketch has unresolved external references") on the features consuming the sketch (`danglingProfileRefs`, applied by `ParametricBodyNode.markUnresolvedExternalRefs` after a successful chain) — with anchored resolution a dangling flag means the edge is gone even at the anchor, a genuine upstream loss), an off-session `SketchSolver` re-solve pulls constrained entities onto moved external geometry (persisted untransacted like the ref snapshots, best-effort on conflicts, skipped while an editor session owns the node — `SketchNode.editingSession` — since the live solver reconciles via `syncExternalRefs`, and a ref type flip there cascades the ref's constraints away untransacted (exposed as `SketchSolver.lastRemovedConstraintIds`; the editor drops their dimension anchors and warns with a status-bar tip)), and `generateShape` appends profile-role ref edges to the sketch profiles, and the editor renders refs purple (dashed for reference role), picks them for constraints (associative kinds only — Coincident/PointOn*/Tangent/Equal/Parallel/Perpendicular; rigid kinds and datum dimensions are rejected with a status-bar tip since pinned geometry cannot move — `allowsConstraintOnEntity` in `solverEntities.ts`), snaps/auto-constrains drawn and dragged points onto them like datum geometry (the shared real + external enumeration is `constraintTargetEntities` in `solverEntities.ts`), and deletes them with a constraint/anchor cascade; `sketch.toggleExternal` flips a picked ref between reference and profile roles (profile-role edges close loops into faces, reference-role ones never build profiles by design). Roles are mostly automatic (`syncExternalRoles` in `sketchModel.ts`, applied by the solver's `toData`/`loadData`): any constraint referencing an unpinned ref derives its role to "profile", a ref no constraint references reverts to "reference"; explicit choices set `ExternalRefData.pinned` (the toggle command, or picking the profile role in `sketch.projectEdges`), which derivation never overrides.
- **`wasm`** — Concrete `ShapeFactory` → OCCT via Emscripten; exports `initWasm()`
- **`three`** — Three.js viewport, camera controller, visuals, highlighter, gizmo, mesh export
- **`element`** — Custom reactive DOM elements (radio groups, expanders, data converters)
- **`ui`** — App chrome: main window, ribbon, property panels, project tree, dialogs, toast, status bar
- **`app`** — `Application`, body nodes (`bodys/`), command implementations, `CommandService`, `HotkeyService`
- **`builder`** — `AppBuilder` fluent chain (`.useIndexedDB().useWasmOcc().useParametric().useThree().useUI().build()`), default ribbon layout; `mergeRibbonProfiles` merges module contributions (`SketchRibbonProfiles` from `@chili3d/parametric`, `ParametricRibbonProfiles`) into `DefaultRibbon`
- **`i18n`** / **`storage`** / **`web`** — Locale data (en, zh-cn, pt-br) / IndexedDB persistence / entry point (loading screen, `?plugin=`/`?url=`/`?model=` params)

Import via workspace names (`import { ... } from "@chili3d/core"`); one root `tsconfig.json` covers all packages.

## C++ WASM (`cpp/`)

OCCT v8.0.0 → `chili-wasm.wasm` via Emscripten. `cpp/src/`: `factory.cpp` (shape creation; the tracked ops report per-output history twice — single-valued `faceMap`/`edgeMap` keeping the first ancestor, plus flat (out, in) `faceAncestors`/`edgeAncestors` pairs keeping every derivation so boolean-merged faces record all their inputs), `shape.cpp` (topology traversal), `converter.cpp` (STEP/IGES/BREP/STL), `mesher.cpp` (B-rep → mesh), `geometry.cpp` (curve/surface queries). Output: `packages/wasm/lib/chili-wasm.{wasm,js,d.ts}`. C++ style: WebKit (clang-format); license LGPL-3.0 (TS is AGPL-3.0).

## Key Patterns

- **Interface-driven** — `core` defines interfaces; feature packages implement; `AppBuilder` wires at startup.
- **Result pattern** — Fallible ops return `Result.ok(value)` / `Result.err(error)` (`core/src/foundation/result.ts`); never throw for expected failures.
- **Reactive data** — `Observable` uses `getPrivateValue(key)` / `setPrivateValue(key, value)`; setting emits `emitPropertyChanged`. `ObservableCollection` powers property editor and project tree.
- **Serialization** — `@serializable()` on classes, `@serialize()` on fields → `{ __cla$$__: "ClassName", ...props }`.
- **Body nodes** — `app/src/bodys/`; extend `ParameterShapeNode`, implement `generateShape(): Result<IShape>`, `setPropertyEmitShapeChanged()` triggers re-evaluation.
- **Commands** — `ICommand.execute(application): Promise<void>`; `CancelableCommand` adds `cancel()`, `AsyncController`, dispose stack.
- **Undo/redo** — `Transaction` records snapshots, `History` keeps the stack; commands create transactions automatically.
- **Plugins** — Loaded from URLs or `?plugin=`; manager in `core/src/plugin/` + `app/src/pluginManager.ts`; examples in `plugins/`.
- **Global singleton** — `getCurrentApplication()` (from `core`) instead of DI threading.
- **MCP server** (`packages/mcp/`) — `live_*` tools drive the user's open browser tab; headless tools (`run_cad_program`, `render_preview`, etc.) are a server-side scratchpad. Units: millimetres; angles: degrees.

## Testing

- Rstest (not Jest/Vitest) + Happy-DOM; root `rstest.config.ts`, globals enabled (`describe`, `test`, `expect`); tests in `packages/*/test/`; legacy decorators enabled.
- Reuse shared mocks from `@chili3d/core/test-utils` (`TestDocument`, `createMockDocument`, `createMockApplication`, `createMockVisual`, ...) instead of per-package copies; package-specific facades (e.g. `packages/ui/test/_helpers/`) extend them. `initializeI18n()` runs automatically via rstest `setupFiles` — never call it in test files.
- Assertions must execute: none hidden in event callbacks (unless the callback is also asserted to fire), no tautologies (`x === true || x === false`), no `if (x) expect(...)` — assert the precondition, then the behavior; `await` every promise whose `.then` asserts.
- Assert behavior, not absence of crashes: bare `not.toThrow()` / `toBeDefined()` is a smell; `querySelector` results need `not.toBeNull()`.
- Restore global monkeypatches (`PubSub.default.pub`, `globalThis.fetch`, ...) in `finally`/`afterEach`, or use `rs.stubGlobal` + `rs.unstubAllGlobals()`.
- Type `rs.fn` mocks with the real signature (`rs.fn((_edges: IEdge[]) => ...)`) so `mock.calls` typechecks; use `test.each` for near-identical repeated cases.

## Code Style

- Biome: 4-space indent, 110-col width, double quotes, semicolons always
- `I`-prefixed behavioral interfaces — plain data-carrier shapes stay unprefixed (`...Data`, `...Ref`, `...Options`, e.g. `SketchData`, `EdgeRef`); `camelCase` functions/variables/files; `PascalCase` classes; `UPPER_SNAKE_CASE` constants
- CSS Modules (`*.module.css`); type-only imports (`import type { IFoo }`)
- Every TS file starts with the AGPL-3.0 header:

```ts
// Part of the Chili3d Project, under the AGPL-3.0 License.
// See LICENSE file in the project root for full license information.
```
